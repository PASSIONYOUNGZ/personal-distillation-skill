# 个人蒸馏 Skill

从一个人的公开经历、文章、视频和作品中，理解他做过什么、怎样判断和解决问题，再整理成有来源、可离线阅读的 HTML。

Personal Distillation Skill — learn from people’s public work and turn concrete examples into methods you can study and try.

**[先看七份完整案例](https://passionyoungz.github.io/personal-distillation-skill/) · [下载 Skill](dist/person-distillation-2026.10.29.4.zip) · [更新记录](CHANGELOG.md)**

当前发布版本：**2026.10.29.4**。技能目录和调用名：`person-distillation`。

## 它能帮你做什么

想系统学习一个人，材料往往散在不同平台：文章里讲观点，视频里演示过程，项目和访谈又补充了不同背景。本 Skill 把这些材料连起来，让你能从具体作品理解这个人的知识、方法与取舍。

适合研究创作者、开发者或其他有公开作品的人；不限定 AI 领域，也不要求你先提出一个工作问题。它用于研究与学习，不是人物扮演或人格克隆工具。

## 阅读版里有什么

- **认识这个人、经历时间线**：介绍角色、代表实践和重要转变，区分事件日期、本人自述与外部记录。
- **内容地图**：按主题或时间浏览，组合使用关键词、主题和推荐星级筛选。
- **深度内容解读**：讲清对象、背景、实际过程或论证、关键例子、取舍与结果；有合适原作图片或视频画面时，放在相应解释旁。
- **观点与看法**：只收值得保留的判断，突出关键短语，可展开已取得并核实的原文。500字以内短帖默认全文；超过500字也不自动截断，确需节选才保留主要内容及必要上下文。
- **做事逻辑与方法、学习方向**：从作品中归纳有依据的做法，说明适用条件，并给出可选择的学习方向。

质量优先：不靠凑数、填满栏目或添加泛泛建议抬高内容价值。没有材料的模块可以隐藏；范围未核全、原文未取得或数量未达到时，如实说明，不把阶段成果标成全部完成。

输出是单文件 HTML，正文、样式、交互与可用图片内嵌其中，可离线阅读。支持配色、展开收起、划词高亮与导出含高亮的阅读副本；打开外部来源仍需要联网。高亮默认保存到当前浏览器的本地存储，是否跨次保留取决于浏览器支持；换设备或清理浏览器数据前，可导出备份。

## 一句话安装

把下面这段发给支持技能的 Agent：

> 请从 https://github.com/PASSIONYOUNGZ/personal-distillation-skill 安装个人蒸馏 Skill。先读 AGENT_INSTALL.md，在当前宿主支持的技能目录中安装并完成基础自检；依赖按实际任务需要准备，最后告诉我可用能力和仍需人工连接的事项。

安装完成后，告诉 Agent **蒸馏谁，以及数量、时间范围或代表作品范围**：

```text
使用 $person-distillation，蒸馏[姓名或作者主页]最近30项公开内容，保存到新的独立目录。
```

将方括号替换为实际人物。不需要另填工具、模型、署名或学习目标问卷。

## 几种常见用法

| 想做的事 | 可以这样说 |
| --- | --- |
| 了解近期更新 | 使用 $person-distillation，蒸馏[姓名或主页]最近30项公开内容。 |
| 研究一段时间 | 使用 $person-distillation，蒸馏[姓名或主页]在2026年9月发布的公开内容。 |
| 从代表作品理解能力 | 使用 $person-distillation，研究[姓名或主页]的30项代表性公开内容，兼顾实践和观点。 |
| 限定平台和形式 | 使用 $person-distillation，只研究[姓名或主页]在B站最近20条有学习价值的视频。 |
| 整理手头的材料 | 使用 $person-distillation，只整理[材料文件夹]里的[姓名]作品与背景，生成阅读版。 |
| 接着上次研究 | 使用 $person-distillation，继续[旧任务目录]，补充[姓名]在2026年10月的新内容。 |
| 修订已有阅读版 | 使用 $person-distillation，优化[HTML或任务目录]中的[具体问题]，保留原版和我的修改。 |
| 审校视频逐字稿 | 使用 $person-distillation，依据[视频链接或文件]审校[稿件路径]，另存纠错稿和待核词。 |

普通“最近N项”以N为目标上限，按质量从近到远筛选；可以有界向前补找，也可以说明停止依据后少收。用户明确要求必须达到N项时才按精确数量处理。代表作品按预算选样，不能冒称严格最近集合。时间与数量同时限定时取交集，跨平台已核同版去重，来源作品数与聚合后的观点数分别计数。人物整体背景另行调查，不被近期作品窗口截断。更多情境见[使用示例](person-distillation/references/usage-examples.md)。

## 使用前需要知道

- **宿主负责浏览器和联网能力。** 核心脚本需要 Python 3.10+，使用标准库；视频工具、FFmpeg 和语音模型按需要配置，不在安装时全部下载。
- **登录由你选择。** 必要的连接、登录和验证码集中说明，允许全部登录、全部跳过或只选部分。默认关注小红书、B站、抖音、公众号、X、微博；其他未明确指定的平台遇到登录墙可略过。跳过影响范围时会保留缺口。
- **不会保证全网穷尽或固定完成时间。** 平台目录、登录和媒体可用性会变化。已有字幕、材料和未变审阅可以复用，但不能用缓存代替必要核读。
- **接续保留原稿和用户修改。** 旧格式任务在新目录按当前要求重建，不沿用旧审阅的通过状态；目前不自动合并多个 HTML，也不自动后台持续监控。

已有仓库副本时，也可运行：

```text
python install.py --skills-dir <当前宿主的技能目录>
```

安装器会逐文件核对并运行合成阅读器自检；遇到内容不同的同名安装会停止，避免覆盖修改。安装成功不代表宿主已发现技能、站点已登录或真实研究已完成。具体步骤见 [AGENT_INSTALL.md](AGENT_INSTALL.md)。

## 仓库与安装包

| 位置 | 内容 |
| --- | --- |
| `person-distillation/` | 可安装的技能：入口、参考规则、脚本、阅读器资源与合成示例 |
| `dist/` | 各次发布的 Skill ZIP，便于核对版本与回退 |
| `AGENT_INSTALL.md`、`install.py` | 安装指引与基础自检 |
| `docs/` | 案例网站、七份公开阅读版及展示资源；不装进 Skill |
| `VALIDATION.md`、`CHANGELOG.md` | 发布验证记录与变更说明 |

Skill 包不含研究人物的底稿、私人配置、登录状态、模型或虚拟环境。包内项目开发者署名、头像和主页是已授权的公开品牌资源，与研究对象及安装者身份分开。网站案例中的第三方作品与头像见各自来源说明。

维护验证与运行边界见 [VALIDATION.md](VALIDATION.md)。计时记录留在本地任务目录，不向远程上传遥测；它用于分析实际阶段耗时，不作为固定速度承诺。
