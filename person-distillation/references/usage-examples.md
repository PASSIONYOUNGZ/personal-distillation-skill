# 自然语言使用示例

只需人物和范围；工具、平台、格式、署名不是必答问卷。姓名不能可靠消歧时补一个主页。默认跨平台同版去重，三星及以上学习价值；人物背景独立于作品数量。

| 想看什么 | 可以这样说 | 实际含义 |
| --- | --- | --- |
| 了解做事方式 | 蒸馏某人的30项代表性公开内容，兼顾实践和观点 | 有界代表集合，软性均衡，不声称最新全集 |
| 严格接近期更新 | 蒸馏某人最近30项公开内容 | 初筛后按时间选取，观点多也不换成旧长文 |
| 偏重深度 | 蒸馏某人最近三个月的代表内容，优先长文和项目 | 在该窗口内优先对应内容；少收不造配额 |
| 只看产品案例 | 研究某人的5个产品案例，解释关键选择与迭代 | 硬限制作品类型；同项目的介绍和演示关联，不重复凑数 |
| 看精选观点 | 整理某人最近20项有价值的短帖，相近观点合并 | 20指来源作品；合并后的观点数量另报 |
| 多看视频 | 研究某人的10条代表视频 | 依字幕、音轨和画面选择合适路径，缺便捷稿时可能较久 |
| 增量继续 | 继续这个目录的研究，补最近一个月的新内容 | 先核原请求与资料版本，复用未变材料；保留固定截止与变更依据 |

没有特别强调最近的代表性请求可以兼顾深度解读、精选观点和产品实践。10—20条观点是易读规模参考，不是每人固定目标；没有产品的人无需产品模块。重要的是让读者看懂具体内容，再看有证据的判断和行动模式。

如果用户说“最多10条观点”，记录scope.viewpoint_limit=10，它限制最终观点单元。不能为凑上限强合并不同含义，或让观点假扮深读。范围与该限制确实冲突时解释具体冲突并补一次必要澄清。

读法是：先识别人和经历，通过主题/时间地图选内容；复杂作品进入深读，短表达进入紧凑观点，最后看做事逻辑和可选学习方向。原作入口和必要原稿可查。方法证据不足时如实保留一例观察或暂不归纳，不用空泛能力标签凑栏目。

已有资料库需用户明确路径或沿当前项目配置；不会默认扫描全盘、后台追踪或上传研究。多HTML自动合并不在当前功能内，稳定集合清单为未来整合留接口。
