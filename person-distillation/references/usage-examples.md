# 个人蒸馏Skill：按你的需要使用

把下面的姓名、主页或路径换成你的实际对象即可。默认交付有来源的离线 HTML 阅读版，包括人物介绍、经历、内容地图、解读、方法与可选学习方向；没有足够材料的栏目不硬凑。工具、模型、署名和学习目标都不是必答项。

## 1. 看一个人最近在做什么

适合：关注近期更新，想按时间了解他的作品、实践和判断。

> 使用 $person-distillation，蒸馏[姓名或作者主页]最近30项公开内容。

默认筛选有学习价值的内容，再按时间向前补足。30项是跨平台核实同版、去重后的来源作品数；解读或合并后的观点数可能不同。不是每个平台各30项。

## 2. 研究某个时间段

适合：复盘一个月、一季度或一次转型期间的公开内容。

> 使用 $person-distillation，蒸馏[姓名或作者主页]在2026年9月发布的公开内容。

只收这个时间段内符合要求的作品，不从区间外补数量。人物整体公开背景独立调查，不会把经历时间线也裁成一个月。

同时限制时间和数量时，可以说：

> 使用 $person-distillation，蒸馏[姓名或作者主页]在2026年7月1日至9月30日期间最近的20项公开内容。

两项要求取交集。区间内不足20项，就报告实际数量与原因。

## 3. 从代表作品理解一个人

适合：更重视能否理解他的能力与做事方式，不要求严格取最近作品。

> 使用 $person-distillation，蒸馏[姓名或作者主页]的30项代表性公开内容，兼顾实践和观点。

这是有界代表集合。会按实质内容、主题变化、实践与反例选样，不能把它称为“最近30项”。数量可换成你的预算；也可以说“近期一些有代表性的内容”，由 Agent 简要说明有界选样方式后执行。

## 4. 只研究某个平台或内容形式

适合：你明确只想看视频、文章、访谈或产品案例，或者只有某个平台与本次问题有关。

> 使用 $person-distillation，只研究[姓名或主页]在B站最近20条有学习价值的视频。

> 使用 $person-distillation，研究[姓名或主页]的5个代表性产品案例，讲清关键选择、迭代和结果。

“只看”是范围限制。若只是偏好，可以说：

> 使用 $person-distillation，蒸馏[姓名或主页]最近三个月的代表内容，优先长文和项目。

“优先”允许其他有价值形式入选；若同时要求严格“最近N项”，偏好不会挤掉时间更近的合格作品。

## 5. 只整理你提供的材料

适合：已有文章、视频、逐字稿或作者资料，不想重新扩展作品范围。

> 使用 $person-distillation，只整理[材料文件夹]里的[姓名]作品与人物背景，生成阅读版。

按提供集合核材料、来源和版本；真实缺口会说明。只给几条种子链接、却要求“最近30项”，仍需要查目录，不能把种子链接当成完整集合。

## 6. 接着已有研究补充

适合：继续未完成的任务，或给已有研究增加一段新内容。

> 使用 $person-distillation，继续[旧任务目录]中尚未完成的研究，先读取原请求和断点。

> 使用 $person-distillation，继续[旧任务目录]，补充[姓名]在2026年10月的新内容。

会核对原范围、作品版本和已有材料，复用未变的原稿与审阅。新增内容与原成果分清，保留旧稿及用户修改；目前不自动拼接多个 HTML。

## 7. 优化已有阅读版

适合：已有成品，希望改排版、交互或修正某些解读。

> 使用 $person-distillation，优化[HTML或任务目录]的阅读体验：调整[具体问题]，保留现有内容和我的修改。

> 使用 $person-distillation，复核[任务目录]的深度解读与观点与看法，重点检查[具体问题]；先给修改对比。

已有底稿有助于核对来源；只有 HTML 时，会区分能直接改的展示问题与需要补原稿的内容判断。“先给对比”不会被当作直接重写的指令。

## 8. 审校一条视频的逐字稿

适合：已经有自动字幕或转写稿，想修正识别错误并保留可追溯的原稿。

> 使用 $person-distillation，审校[姓名]这条视频[链接或视频文件]的逐字稿[稿件路径]，保留原稿，另存有依据的纠错稿和待核词。

按声音、画面或其他明确证据最小纠错；不会把口语改写成文章。缺少可核证据的词会留下待核，不把模型猜测当成原话。

## 可以补充的偏好

这些都可直接附在请求后，不必逐项回答。

| 偏好 | 可追加的话 | 会怎样处理 |
| --- | --- | --- |
| 更关心做事过程 | 重点解释他的选择、试错和反馈 | 改变解释侧重，不凭空补过程 |
| 观点少一些 | 观点与看法最多8条，宁缺毋滥 | 限制最终观点单元数；不把8条当必达数量，也不改变来源作品数 |
| 想看短帖中的判断 | 只整理最近20项有价值的短帖，相近观点可合并 | 20仍指来源作品；不是要求产出20条观点 |
| 保留完整原集合 | 最近20项全部保留，不按推荐度筛除 | 按明确要求保留，仍区分质量与材料不足 |
| 改交付格式 | 这次交付Markdown | 尊重格式选择；没有指定时交付离线HTML |

普通请求从以上一种开始就够了。严格最近集合需要核实各相关目录的时间边界，视频可能需要字幕、声音和关键画面；实际缺口会说明，不以缺材料冒充完成。
