# B站：投稿目录与字幕分别验证

1. 互链核UID，进入原生空间投稿页，确认最新发布及类型；保存BV、日期、标题、原链、分P、置顶。合集可能重复，BV＋分P处理版本，搜索样本不是目录。

人物头像只取该已核UID的空间作者资料区，或其作品页中指向同UID的UP主资料卡。顶部导航、个人中心、评论输入框中的头像通常属于当前登录者，不能作为研究人物头像；不要按页面第一张头像或通用avatar类名提取。保存profile.avatar.account_url为实际核过的space.bilibili.com/UID，并在selection_reason说明昵称、UID和作者资料区的对应关系；下载后再查看图像并与该资料区对照。URL字段相符不证明图片正确。无法核对时暂不显示人物头像或沿已核的另一主账号获取，不能拿登录者头像补位。
2. 保存一页，再翻页／滚动一次核新增ID。原生页明确登录门槛才集中登录。匿名API的412、HTTP200业务码-799或频率提示记受限／限流，停该API；至多正常浏览器核一次，不换接口／参数规避频控。
3. 单片核作者、简介、章节、时长。Agent自行暂停／静音，再检查实际字幕轨。头像不证明字幕可取；工具返回空不证明全平台没有稿。
4. 已有兼容BBDown先读本机帮助，再试`--sub-only --skip-ai false -p ALL --work-dir <新单片目录>`。核本次非空SRT、BV／分P、语言、首尾和中段，退出码0不够。yt-dlp也只按当场已验证能力使用，不因支持站名就假定作者目录或AI字幕可用。
5. 无稿比较已核同版其他入口；否则正常独立音频→FFmpeg→本地ASR，不能用简介、章节或弹幕代替口播。候选含视频时即准备一条路线，不等全批下载后发现缺依赖。

BBDown[官方仓库](https://github.com/nilaoda/BBDown)已归档（2026-10-13核验），仅保留已有兼容路线；新用户不默认有此工具，不强制安装失去维护的工具或未核同名fork。新环境按[部署](release-and-validation.md)准备当前适用工具并实测。

单片成功、目录边界与全部视频理解分别验收。限流遵守恢复时间，不轮换账号、代理或接口规避。会话留工具授权存储，发布包不携带。
