# 个人蒸馏案例页

在线入口：https://passionyoungz.github.io/personal-distillation-skill/

GitHub Pages 发布源：`main` 分支 `/docs`。`index.html` 为案例目录；`examples/` 为七份原始单文件阅读版，原始字节与下载文件保持一致；`assets/` 仅保存从阅读版提取的公开账号头像。

案例以各自开头的研究截止时间和范围说明为准，不因网站发布日期改变。案例不是技能安装包的一部分，不对其所用 Skill 版本作额外推定。第三方作品版权及引用归属见阅读版。

更新案例时替换相应 HTML，更新 `examples-manifest.json` 的字节数和 SHA-256，并同步首页的文件大小。请勿将本地研究底稿、账户信息或私人路径一并上传。
